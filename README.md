## 数据口径

- 信息获取时间：2026-10-07（北京时间）
- 评分：10 分制主观共识分，综合科技媒体评测、第三方横向实测与用户社区口碑，非官方/实验室客观测量，同一产品不同评测体系存在 ±1 分差异
- 价格：海外产品以 USD 为主，约合按 1 USD ≈ 7.1 CNY 估算；部分价格为第三方转述，标注"待确认"
